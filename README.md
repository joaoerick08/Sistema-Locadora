# Sistema Locadora

Sistema de gerenciamento de locadora de veículos desenvolvido em Java e PostgreSQL.

## Funcionalidades

- Cadastro de clientes
- Cadastro de funcionários
- Cadastro de veículos
- Registro de aluguel
- Consulta de veículos disponíveis

## Tecnologias

- Java
- PostgreSQL
- JDBC
